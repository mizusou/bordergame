## FRONT/IER

A daily geography game where you guess two countries by the border inbetween them. 
Website built with HTML, CSS, TS, and border logic and map fetching in Python. Deployed on Cloudflare Workers for free (thanks cloudflare)


## Local Development (if you want)
### Prerequisites
- Node.js 18+ or 20+
- npm or pnpm
### Setup
```bash
# Clone the repository
git clone https://github.com/mizusou/bordergame.git
cd bordergame
# Install dependencies
npm install
# Start development server
npm run dev
```
### AI tools
This game was made with the help of AI tools for some of the coding, namely Google Antigravity w/ Gemini Flash 3.8.
